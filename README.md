# git-practice

GitHubの基本操作を練習するためのリポジトリです。  
この課題では、以下の流れを体験します。

- リポジトリを clone する
- branch を作成する
- ファイルを編集する
- commit する
- push する
- Pull Request を作成する

## 練習内容

1. このリポジトリを clone します
2. 自分の branch を作成します
3. `students` フォルダの中に、自分の出席番号のフォルダを作成します
4. `index.html` を参考にして、自分のファイルを作成・編集します
5. commit して push します
6. Pull Request を作成します

## branch名

branch名は自分の氏名、または分かりやすい名前にしてください。

例

- `yamada`
- `tanaka`
- `suzuki`

## フォルダ作成ルール

`students` フォルダの中に、自分の出席番号のフォルダを作成してください。

例

- `students/01/`
- `students/02/`
- `students/03/`

## 提出方法

Pull Request を作成した時点で提出とします。

## 注意

- `main` ブランチでは作業しないこと
- 他の人のフォルダやファイルは触らないこと
- merge はしなくてよいです
